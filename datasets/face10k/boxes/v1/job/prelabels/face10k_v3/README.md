# face10k — 多人脸标注集（2026-08-10 定版）

给外包标注用的万张集。标注口径见 [ANNOTATION_SPEC.md](ANNOTATION_SPEC.md)，
分层抽检见 [preview_strata/](preview_strata/)（18 张表 / 180 张样本，按"画面里有几张确信人脸"分三组）。

## 为什么这么挑

客户反馈的是**漏检**，所以按现网检测器去挑帧没用——那只会挑出我们**已经检得到**的脸。
挑法是反着来的：每帧用 **0.10 低阈值**重跑，再按现网那道门（续轨 seed 阈值 0.75）分类：

- `n_hi` = 分数 ≥ 0.75 → 现网会在这里起一条轨，**会打码**
- `n_lo` = 分数落在 [0.50, 0.75) 且长边 ≥ 40 px → **现网直接丢掉，这就是客户在抱怨的召回**

| 档 | 条件 | 张数 |
|---|---|---:|
| `miss_multi` | `n_lo ≥ 1` 且 `n_hi + n_lo ≥ 2`（多人脸，且其中有我们会丢的）| **7,921** |
| `multi` | `n_hi ≥ 2`（多人脸，本来就检得到）| **418** |

## 为什么阈值定在 0.50

抽检发现预标框里很多不是脸。用 10 条人工 GT 序列量了一下，一个检测框**真的落在脸上**的
概率随分数急剧变化：

| 分数段 | 命中率 | 分数段 | 命中率 |
|---|---:|---|---:|
| 0.30–0.35 | 10.7 % | 0.50–0.60 | 70.4 % |
| 0.35–0.40 | 16.1 % | 0.60–0.75 | **95.6 %** |
| 0.40–0.50 | 42.1 % | 0.75–0.90 | 99.9 % |

原来挑帧用 0.35、画提示框用 0.30——**三分之二画出来的东西是植物和桌沿**。
0.50 是价值分界：往上大概率是真脸，往下不到 0.75 现网还是会丢，
**正是花钱标最值的样本**。0.35–0.50 那一段基本是布景。

选帧和画框两处阈值一起提到 0.50，不重挖：每张已存图都留了 0.30 以上的全部检测和分数，
类别按新阈值重算，最好候选低于 0.50 的图直接出局。

一个已知上限：GT 里 20,000 张脸中有 **18,698 张**在 0.10 阈值下能被检到，
也就是**约 6.5 % 的脸这套挖法根本看不见**，得靠标注方补框。

## 三组分层抽检看到了什么

按一帧里有几个 ≥0.75 的框分三组看（[preview_strata/](preview_strata/)）：

| 组 | 占比 | 内容 |
|---|---:|---|
| A `n_hi ≥ 2` | 30.2 % | 车间多工人，绿框落在真人头上；也有一格 `StockShelf-InstantDrink` 五个高分框全在奶粉罐婴儿照上 |
| B `n_hi = 1` | 44.7 % | 一个确信真人 + 一批 0.50–0.75 候选，候选一半是远处真人、一半是印刷包装 |
| C `n_hi = 0` | 25.1 % | 印刷包装人脸（precision 负样本）**和现网完全放掉的远处真人**（`OrganizeItem-Belts` 门口 0.73、`SortItem-Clothespins` 桌边 0.63）——最难的召回样本 |

C 组不是废料。我先前把它当成噪声是判断错了：它同时承担 precision 负样本和最难召回样本两件事。

## 标注口径（v5，2026-08-11 定稿）

**2026-08-11 与客户和上级讨论后定案**：卡通与玩偶脸不打码，真人脸和印刷/屏幕人脸都打码。
于是 v4 的三类塌成**一件事**：

> **能认出是哪个具体的人 → 框（现场活人 / 屏幕里的真人 / 印刷的真人照片，不区分）**
> **认不出 → 不框（卡通 / 手绘 / logo / 玩偶 / 模特假人）**

**类别字段取消**，每框只填「不确定」。朝向 / 遮挡 / 模糊在 v4 已取消。

**同时定案：双目物理宽度判据不再做**（`方案对比-2026-08-11.md` 里的 T2 等方案全部搁置），
玩偶不被打码这件事**改为完全由检测模型承担**。

⚠️ 这有两个直接后果，落在标注上：

1. **最难的判断没有消失，只是从「填哪一类」变成了「框不框」**——印刷的真人照片 vs 卡通画，
   仍然是同一道题。区别是**错了看不见**：标错类别还留着框可以复核，漏框则静默丢失。
   所以规范里保留「不确定」，并明确**拿不准一律框上 + 勾不确定，不确定框由我方复核后再决定是否进训练**。
2. **"卡通/玩偶不框"现在是唯一的负样本来源**。以前有宽度判据兜底，现在没有了，
   这批标注里那些**被删掉的提示框**就是模型学会"这不是要打码的脸"的全部依据。

验收口径也跟着改：不再考核类别正确率，改为
**漏框 <2%，其中「把印刷/屏幕真人脸当卡通跳过」<0.5% 单独考核**（同一个失效，换了名字）。
