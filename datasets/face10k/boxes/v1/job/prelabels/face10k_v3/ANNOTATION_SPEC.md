## 一、这批图是干什么用的

我们的系统要在视频里**自动把人脸打上马赛克**，保护被拍到的人的隐私。

现在有两个毛病：

- **该打的没打上**：有些人脸系统认不出来，就露在视频里了
- **不该打的打了**：把包装上印的娃娃脸、玩偶的脸也糊掉了，客户很不满

你们要做的事只有一件：**把该打码的人脸框出来，不该打码的不要框。**

### 第二批 `repair_v1` 有什么不一样

**只有一点**：这批图上已经有框了，需要你们**重画**。

这些框原本标在去畸变后的画面上，我们把它转换到鱼眼原图时，在画面**周边**遇到了转换上的问题，
结果部分框变成了横条或竖条，只盖住脸的一个切片而不是整张脸。

**这不是上一批标注员标错了，是我们的坐标转换在画面周边不可靠。**

所以请**直接在鱼眼原图上重新画**，这样不经过任何转换。清单里两个字段：

| 字段 | 说明 |
|---|---|
| `pre_boxes` | **要重画的框**——位置大致可信、**形状不可信**，当作"这附近有张脸"的提示 |
| `kept_boxes` | 同一张图上**已确认没问题**的框，**不用动**，供参考 |

其余一切照旧：只框人脸、不分类、每框只填「不确定」。

`manifest.jsonl` 每行一张图，含图片路径、宽高、以及机器预标的提示框。
**你们交回来的行顺序要和它一致。**

## 四、只有一件事要判断

看到一张"脸"，问一句：

> ### **能不能认出这是哪一个具体的人？**

| 答案 | 例子 | 怎么做 |
|---|---|:---:|
| **能** | 现场的活人；手机/电脑/电视**屏幕里正在播的真人**；**印在东西上的真人照片**（奶粉罐婴儿照、包装模特、海报明星、工牌照、说明书上的人）| **框出来** |
| **不能** | 卡通、手绘、简笔画、logo 里的脸、拼音挂图上的卡通小孩、贴纸；仿真婴儿娃娃、服装店模特头 | **不要框** |

**只有这一条分界线。** 现场活人和印刷/屏幕里的真人**不用区分**，都框，一视同仁。

### 最容易混的：印刷的真人照片 vs 卡通画

同一个包装上，**可能既有真人照片也有卡通图案**。

- 看起来像**拍出来的照片**（有真实的皮肤、头发、光影）→ **要框**
- 看起来像**画出来的**（线条、色块、夸张的大眼睛）→ **不框**

### 拿不准怎么办 —— 这条最重要

> **拿不准就框上，并勾「不确定」。**

**千万不要因为拿不准就跳过。** 跳过了这张脸就永远消失了，我们再也看不到；
框上并勾「不确定」，我们会人工复核，判错了也能救回来。

**宁可多框，不要漏框。**

### 关于仿真娃娃

有一类任务全程在给**仿真婴儿娃娃**穿衣服，画面里会同时出现**真人的手**和**娃娃的头**。

- 娃娃的头**不框**（塑料光泽、眼睛是画上去的、没有眉毛睫毛）
- 但同画面如果有**真人露脸**，那张脸**照样要框**
- **看着像真婴儿、拿不准是不是娃娃 → 框上 + 勾「不确定」**

## 五、提示框怎么用

每张图上已经画了**提示框**，那是机器猜的"这里可能有脸"。

**提示框只是提示，机器经常猜错，而且它分不出卡通和真人。** 你要做四件事：

| 情况 | 怎么做 |
|---|---|
| 框对了 | 保留 |
| 框歪了 / 大小不对 | 拖到位（见 §六）|
| **框错了**——框在瓶盖、桌角、自己的手上，**或者框在卡通/玩偶脸上** | **删掉** |
| **有脸没被框**（机器漏了）| **自己补一个框** ← 这一项最重要 |

机器漏掉的脸，正是我们最需要的。**看到该框的脸就框，不管机器有没有标出来。**

## 六、框怎么画

### 画到哪里

**紧贴能看见的那部分脸**：上到发际线，下到下巴尖，左右到脸颊外缘（或耳朵前缘）。

- **不要**把头发、耳朵、脖子、帽子框进去
- **侧脸只框看得见的半边**，不要凭想象补出被挡住的另一半
- 被东西挡住时，**只框露出来的部分**，不要框到挡住它的东西上
- 框贴紧，四边留的空白不超过脸本身的 5%

### 什么要框

**只要能看出眼睛、鼻子、嘴当中的任意两样，就框。**

- **再小也框**（远处的人只有指甲盖大小，也框）
- **再模糊也框**（人在动、拍虚了，只要还看得出是脸）
- **再暗也框**（车间光线差）
- **戴口罩、护目镜、面罩**的：只要露出的部分够上面那条，就框
- **变形的**（画面边缘被鱼眼拉扯）：照样框

### 什么不框

- **卡通 / 手绘 / 玩偶 / 模特假人**（见 §四）
- **纯后脑勺 / 完全背对**（五官一样都看不见）
- 只剩耳朵、或只剩下巴的边角残片
- 模糊到认不出五官的反光、影子
- 放大到最大也认不出是不是脸的几个像素点

## 七、每个框只填一样

| 字段 | 填什么 |
|---|---|
| **不确定** | 是 / 否（你拿不准这是不是脸，或者拿不准是真人还是卡通/玩偶）|

**没有类别字段。** 脸的大小、朝向我们自己从框和图算，不用你填。

## 八、交回来的格式

每张图一行，**顺序和 `manifest.jsonl` 一致**。一张脸都没有的图**也要出一行**，`boxes` 留空数组。

```json
{"image": "images/20260622_004450_RBUSKS_023_f007035.jpg",
 "boxes": [
   {"box": [1867.2, 340.5, 1960.2, 418.6], "不确定": false},
   {"box": [612.0, 903.4, 668.5, 971.2], "不确定": true}
 ]}
```

`box` 是框的**左上角和右下角坐标**，顺序为 `[左, 上, 右, 下]`，单位是像素，
原点在图片左上角。坐标必须落在图片范围内（宽 2328、高 1748）。

## 九、验收标准

| 项 | 要求 |
|---|---|
| **漏框**（该框的人脸没框）| **少于 2 %**（我们会抽 500 张逐一核对）|
| **其中：把印刷 / 屏幕里的真人脸当卡通跳过** | **必须低于 0.5 %**（这一项单独考核，超了整批退回）|
| **多框**（框在不是脸的东西上，或框在卡通/玩偶上）| 少于 2 % |
| 框的准确度 | 与我们复核的框重合度达标的比例不低于 95 % |
| 字段完整 | 100 %，不允许缺项 |

抽检不合格的批次**整批退回重做**。

> **为什么"漏框"比"多框"严得多**：多框我们复核时能删掉；漏框我们看不见，那张脸就永远丢了。
> 所以任何犹豫都往"框上 + 勾不确定"那边靠。

## 十一、几个最容易出错的地方（请务必看完）

| 常见错误 | 正确做法 |
|---|---|
| 只框机器画了框的地方 | **机器漏的才是重点**，看到该框的脸就补框 |
| 觉得太小/太模糊就跳过 | **小的、模糊的、暗的都要框** |
| 把包装上印的婴儿照当成"卡通"跳过 | 印刷的**真实照片**要框；只有**画出来的**才不框 |
| 拿不准就跳过 | **拿不准要框上 + 勾「不确定」**，跳过等于永久丢失 |
| 把远处的真人当成"不是脸"跳过 | 远处只要能看出两样五官就框 |
| 机器在卡通/玩偶上画了框，就留着 | **删掉**——机器分不出卡通和真人 |
| 框把头发和帽子包进去 | 只框脸 |
| 画面边缘变形的脸不框 | 变形也要框 |
| 纠结屏幕里的人和现场的人 | **别纠结，都要框，不用区分** |
