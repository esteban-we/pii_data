# 人脸重标批次 repair_v1

3168 张图 / 3686 个待重标框，2026-08-11 生成。

## 这批是什么

这些框原本标在**去畸变后的 1280×720 交付片**上，我们把它映射回**鱼眼原图 2328×1748**时，在画面周边遇到了数学上的病态问题——同一个矫正图矩形可以对应多个原图形状，结果部分框变成了横条或竖条，只盖住脸的一个切片而不是整张脸。

**所以这批不是标注员标错了，是我们的坐标转换在周边不可靠。**
解决办法就是请标注员**直接在鱼眼原图上重画**，这样不经过任何映射。

## 怎么标

口径与 `face10k_v3` 完全一致（同一份 `ANNOTATION_SPEC.md`，同一个 2328×1748 鱼眼空间）：

- **只框人脸，不分类**；每框只填「不确定」
- 能认出是哪个具体的人 → 框（现场真人 / 屏幕里的真人 / 印刷的真人照片）
- 认不出 → 不框（卡通 / 手绘 / logo / 玩偶 / 模特假人）
- 拿不准 → 框上 + 勾「不确定」

## 字段

| 字段 | 说明 |
|---|---|
| `pre_boxes` | **需要重画的框**（形状不可靠，位置大致对）|
| `kept_boxes` | 同一张图上**已经确认没问题**的框，不用动，供参考 |
| `reason` | 为什么进这批 |

⚠️ `pre_boxes` 的**位置大致可信、形状不可信**。请当作「这附近有一张脸」的提示，重新贴合地画。
